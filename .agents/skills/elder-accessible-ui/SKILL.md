---

## Goal
Meet WCAG AA with an interface an elderly person can use alone.

## Rules
- Base text 18px or larger, strong contrast, visible focus rings.
- One primary action per card; buttons at least 48px tall.
- Semantic HTML, labelled inputs, ARIA only where needed, full keyboard use.
- Plain, short wording. No jargon, no time-limited interactions.
- Check both light and dark modes.
